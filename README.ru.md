# AppSec Messenger

[English version](README.md)

Учебный мессенджер — клиентский стенд для изучения AppSec.
На чистом HTML, CSS и JavaScript.

Проект — часть самостоятельного учебного плана по AppSec. Служит
фундаментом для следующего этапа обучения: построения Flask-бэкенда
и демонстрации типичных веб-уязвимостей (SQLi, XSS, broken auth)
на базе этого клиента.

## Стек

- HTML5
- CSS3 (Flexbox)
- Vanilla JavaScript (ES6+)

## Функционал

- Форма регистрации с клиентской валидацией:
  - Логин (минимум 3 символа)
  - Формат email
  - Пароль (минимум 6 символов)
  - Подтверждение пароля
- Логин сохраняется в `localStorage` и отображается в сайдбаре
- Интерфейс чата с тремя контактами
- Переключение между контактами
- Отправка сообщений по клику и Enter
- Автопрокрутка к последнему сообщению

## Структура проекта

## Как запустить

1. Клонировать репозиторий:
   ```bash
   git clone https://github.com/foxxxymiron/appsec-messenger.git
   ```
2. Открыть папку проекта в VS Code.
3. Открыть `index.html` через Live Server (или любой локальный сервер).
4. Зарегистрироваться с любыми корректными данными — произойдёт переход в чат.
